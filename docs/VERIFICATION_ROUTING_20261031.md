# 自检预算与技能路由修复

日期：2026-10-31，中国标准时间。

## 范围

仅调整自检构造、复核恢复、阶段预算与技能路由、规格解释规则。
不修改模型权重、赛事 baseline、独立 judge、候选排名或简单题接受门槛。
未恢复固定端口、固定上下限或固定题目答案的算法模板。

## 自检流程

- 生成单次默认 150 秒、复核 45 秒、每轮检查器阶段总计 240 秒，分别配置。
- `AGENT_CHECKER_GENERATION_S`、`AGENT_CHECKER_REVIEW_S`、
  `AGENT_CHECKER_TOTAL_S` 独立生效；旧 `AGENT_CHECKER_S` 仅兼容生成上限。
- 生成前保留复核与至少 30 秒仿真余量；为后续 RTL 修复保留最多 180 秒，
  且不超过该阶段开始时剩余工作时间的 35%。整题仍受 900 秒硬预算约束。
- 请求超时或截断后明确要求短循环、短标签、完整 JSON。
- 复核传输或响应格式失败最多重试一次原检查器，明确拒绝才独立重建。
- 记录并拒绝重复无效回复；复核重试日志分别保留，未批准的检查器不执行。
- 去除 task automatic 示例的 Markdown 反引号；说明 settle 仅延时、不产生时钟，
  时序检查须显式驱动采样边沿，参考模型须保留数学位宽和有符号比较。
- 复核只检查题面适用的行为，不要求同步复位电路提供异步复位效果。

生成输出仍上限 2048 token、复核 512 token。完整性与正确性门槛保持严格；
更长等待不能保证模型遵守协议或输出正确参考模型。

## 技能路由

- 完整单词或短语匹配，短语可跨换行；具体短语优先于孤立单词。
- assigned、unsigned_result 不再命中 signed；unsigned 作为独立合法算术触发词。
- 移除仅凭 Mismatches 就注入时序、FSM 或串口领域规则的通用触发。
- 新增通用表格技能，按当前题面实际行列标签、变量顺序和有效格解释真值表、
  卡诺图；不假设二进制或格雷码排列，不提供固定表格答案。
- 补充通用有符号扩位、负常量语法、比较边界检查规则。
